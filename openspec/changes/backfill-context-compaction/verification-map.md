## Layer Rules

- Use `unit` for retained-message selection, runtime-context stripping, summary input bounding, threshold calculations, projection replacement mechanics, and failure-path reducers.
- Use `integration` for Slack runtime timing, status behavior, active/awaiting session selection, persisted thread-state pointer updates, and passing compacted `piMessages` into assistant execution.
- Use `eval` for model-visible continuity after compaction when correctness depends on the summarizer and final model interpretation.
- Use `manual` for storage architecture decisions that are not themselves runtime behavior.

## Coverage Action Meanings

- `keep`: Current test/eval covers the scenario with the right scope and name.
- `rename`: Coverage is right, but taxonomy/name is misleading.
- `split`: File or case mixes multiple capabilities and should be separated.
- `move`: Coverage belongs in a different layer or package.
- `replace`: Existing coverage is low-fidelity or asserts the wrong contract.
- `delete`: Existing coverage duplicates another stronger check or asserts non-contract internals.
- `add`: No current coverage exists.
