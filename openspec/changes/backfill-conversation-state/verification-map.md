## Layer Rules

- Use `unit` for state coercion, message upsert/marking, context rendering, title source selection, visible compaction reducers, stats, and malformed-state behavior.
- Use `integration` for Slack thread backfill, queued/skipped message persistence, vision hydration interaction, pending auth pointer updates, active/last session pointer use, and final delivery state patches.
- Use `eval` only when assessing whether the model interpreted visible conversation context correctly, and map those cases to `agent-turn-handling` or `agent-prompt`.
- Use `manual` for ownership and migration decisions.

## Coverage Action Meanings

- `keep`: Current test/eval covers the scenario with the right scope and name.
- `rename`: Coverage is right, but taxonomy/name is misleading.
- `split`: File or case mixes multiple capabilities and should be separated.
- `move`: Coverage belongs in a different layer or package.
- `replace`: Existing coverage is low-fidelity or asserts the wrong contract.
- `delete`: Existing coverage duplicates another stronger check or asserts non-contract internals.
- `add`: No current coverage exists.
