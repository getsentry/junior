# Junior brand assets

`junior-fullbody.png` is the original full-body Junior illustration. Keep it unchanged. Make all other Junior images from it.

| Image                                                    | Source crop                          | Size     |
| -------------------------------------------------------- | ------------------------------------ | -------- |
| `packages/docs/public/junior-character.png`              | Full body, trimmed to visible pixels | 576 wide |
| `packages/docs/public/junior-mark.png`                   | Head, cap, and antennas; transparent | 192x192  |
| `packages/docs/public/favicon.png`                       | Same head crop                       | 96x96    |
| `packages/junior-dashboard/src/assets/junior-avatar.png` | Same head crop                       | 512x512  |

The head crop stops at the bottom edge of the head. It removes the hoodie and the phone. It keeps a small transparent margin and centers the head in a square.

The dashboard uses `junior-avatar.png` for the header logo, the favicon, and the install icon.
