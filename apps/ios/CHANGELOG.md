# Changelog

The format is [Keep a Changelog](https://keepachangelog.com/en/1.1.0/). The app
shows this file in Settings. After an update, it shows the sections for the new
builds once. A release section must have the build number after `+`, such as
`## [0.1.0+42] 2026-11-20`.

## [Unreleased]

### Added

- On iPad, the app uses the full screen. Each list shows next to the item that
  you open.
- On a wide screen, the details of a conversation show in a panel at the side.
- On iPad, the app works in all orientations.
- On iPad, you can open more than one window. Each window shows its own screen.
